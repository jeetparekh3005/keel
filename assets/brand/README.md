# keel brand assets

The keel identity is a cyanotype: the keel of a ship drawn as a shipwright's blueprint,
a precise hairline on a prussian-blue sheet with a station grid behind it and a single
amber datum marking the measurement origin. The name is the structural first beam a ship
is built on; the drawing is the moment before anything else exists.

## Files

| File | Use |
|------|-----|
| `keel-mark.svg` | Primary mark, prussian ground. Avatars, favicons, dark contexts. |
| `keel-mark-light.svg` | Light-ground companion (ink on pale paper) for light READMEs and UIs. |
| `keel-wordmark.svg` | Horizontal lockup with the drafting titleblock. Headers, docs. |
| `keel-mark-512.png`, `keel-mark-128.png` | Raster mark. |
| `keel-favicon-32.png` | Favicon. |

## Palette

| Token | Hex | Role |
|-------|-----|------|
| prussian | `#0C2E52` | the blueprint sheet |
| chalk | `#EAF2FB` | the keel line |
| station | `#5E92C0` | the grid |
| datum | `#F2A541` | the measurement crosshair |
